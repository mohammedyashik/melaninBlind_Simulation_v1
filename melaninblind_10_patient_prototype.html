Dashboard Logic

The second graph is not only the abnormal curve. It is the direct paired comparison: lesion magnitude minus adjacent-skin magnitude, shown as percentage difference at each frequency. The prototype EIS index is calculated from paired magnitude difference, phase difference, and curve-shape difference across the 1 kHz-2.5 MHz sweep. It is an MVP display value only and is not a validated clinical score.
